## 1. Why this is an implementation card

T15's accepted follow-up ruling (T15-PROPOSAL §6.4) deferred UC1/UC2 as
separate cards. The m6 (opencode plugin) and m7 (hermes plugin) drops proved
the typed pause/resume chain end to end on two **plugin hosts**. The library
is the **third host shape**: no slash commands, no hook dispatcher — the app
author drives it explicitly. Every UC1 semantic already exists as a validated
TS module — `packages/opencode/src/uc1-handoff.ts` (661 lines: `uc1Pause`,
`resumeVerify`, `snapshotDigest`, `rustBinDir`, `pauseTurnFromEnv` + mirrored
`PauseResult`/`ResumeResult` contracts) and its hermes twin
(`packages/hermes/src/uc1_handoff.py`) — so this card *ports a proven module*,
it does not re-design UC1. The do-not-touch rule (no `packages/opencode|node|
hermes` edits) fixes the delivery mechanism: **mirror the module into
`packages/ai-sdk`** under the file-naming law (`src/uc1-handoff.ts`), same as
every prior mirror.

key at all**: mock session → mid-stream flush → `pauseAll(turn=N)` → fresh
`createCtxvmCapture({ resumeFrom })` boot-verified → continue → flush.

## 6. UC2 verdict (recorded in this card, no separate card proposed)

UC2 forensics (`ctxvm profile`/`diff`/`replay` CLIs) operate on RFC-0 trace
files — **host-agnostic already**; T15's drop is a first-class input today
(replay/profile of corpus/m8 is how its card was validated). The parity kit
verifies captures from any harness. A `UC2-SDK` card would add no engine or
glue — only docs. Verdict: **no UC2 port card**; if the orchestrator wants
the ai-sdk README to carry a forensics paragraph, that rides T22's docs.
