# RR-POLICY-20261116 — a destructive command may never target the home directory

Owner rule, standing, 2026-11-16: **never suggest, type, or endorse `rm -rf ~` or any recursive delete
targeting `~`, `$HOME`, `/`, or a bare path that could resolve to the home directory.** A cleanup names the
exact subdirectory; `~` is never the target root. Non-negotiable.
