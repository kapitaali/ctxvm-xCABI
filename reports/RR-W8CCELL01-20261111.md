## 4. My attribution finding extends — the capture's `plugin` block is not a record of the arm

The paged arm's own capture (`local-31896a30da46…`, flushed 20:37:12) reads:

```
plugin: { version 0.12.1, engine ctxvm, engineSelections 43, profile "w8cn-paged", arm "paged",
          engineSetting "compressor", skippedControl 0, budgetTokens 200000, budgetSource "default" }
```

The arm, the profile and the selections are right ✓ — but the **budget is wrong**: the run used
**60,000** and the capture says `200000/default` (the control's budget). Same mechanism as
`reports/RR-W8CATTR-20261111.md`: the arm fields (and the budget) are **process-global** and read **at
flush time**. So the capture's `plugin` block is not a record of the arm's configuration at all — it is a
record of whichever session flushed last. **Consequence for the block and the pair: the arm's
configuration must be taken from the run (the probe's verdict, the runner's printout, the block's own
commit), never re-read from a capture afterwards** — and the session-keyed fix (arm fields *and* budget
keyed by `session_id`) is what makes a capture self-describing.

One more measured detail worth having: **both** arms show `proseMentions` **190** and 21 pages / 20 turns
✓ — the observer ran in both arms and the scan saw the same prose in both, which is the strongest
statement yet that the signal was *removed* rather than *disabled* ✓ (and it is what my earlier
checklist predicted the control arm would show).

## 6. The two instrument fixes this run demands (endorsed; both are prerequisites, not re-runs)

1. **Engine → observer reporting.** The engine reports its per-selection decision
   (`evicted_tokens`, `dropped_refs`) to the plugin, which emits `page.evict` per dropped page and sets
   `turn.render.evictedTokens`. Until then the *trace* cannot witness the policy, so the request series
   and the provider receipts are the only evidence a cell can rest on — and the cell's own rule (the
   verifier reads the trace) then cannot be satisfied by a run that **is** a treatment.
2. **Arm-aware verifier.** `engine selections > 0` becomes `selections == 0` for `arm == control`. A
   correct control must never be labelled VOID.
