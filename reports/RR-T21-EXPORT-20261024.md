## 2. The slice rule (pinned here for RFC-0)

The slice for turn N is the **positional prefix** `events[..= cut]` where `cut` is the LAST event
whose turn is ≤ N. Turn-less events before the cut are kept (declaration bookkeeping, `session.open`,
`page.pin`/`page.unpin`); turn-less events after the cut — true trailing bookkeeping — are excluded.
`N` defaults to the trace's last turn fact; N ≥ max-turn degenerates to the identity (full export).

The subtle case is the tracer's **tail flush** (turn-level facts flush at `finish()`, each row
carrying its own turn label — every corpus trace, m1–m3, ends in such a block): rows of turns > N
land physically before the cut and are swept into the slice. That sweep is **inert**, and this card
proves it in-repo:

- `Playback::mode_at(N)` ignores every state change whose effective turn is > N — swept decisions
  cannot distort the turn-N projection (test: `projection_ignores_swept_turn_two_eviction`).
- Any fact inside the prefix is derived from changes with turn ≤ (its own turn) ≤ N, which are all
  pre-cut by the cut's definition — so `replay(&slice)` is divergence-free whenever the source is
  clean (test: `replay_and_diff_witness_the_slice`).
- Because the slice is a positional prefix, `diff(slice, source)` is exactly the extension relation
  with a shared prefix — the UC1 §3 step-4 verify UX holds verbatim (witnessed below).

Declared-onset semantics follow the locked engine law (declared ⇒ in-pool, render facts are the
delivery evidence; the same accounting m3's constant `residentTokens` shows) — turn facts in the
fixture test record final-schedule values, consistent with the replay gate.

## 3. DQ checks (manifest `dataQuality`, ODPS dimension flavor per UC3 §memo)

| check | dimension | content |
|---|---|---|
| `replayDeterminism` | validity | `replay(&slice)` divergences empty (the replay gate, sliced) |
| `sourceFidelity` *(added this card)* | validity | the slice extends the source positionally: `diff_traces(slice, source)` = extension with shared prefix == kept events (the `ctxvm diff` verify UX, self-witnessed) |
| `pinLint` | completeness | pin-family playback violations in the slice (`pin/unpin` of undeclared pages, evict-while-pinned, unpin-of-unpinned) + pinned-yet-stubbed slots at N (working-set zombies) |
| `redactionScan` | uniqueness | 7 credential-shaped patterns (`sk-`, `AKIA`, `ghp_`, `github_pat_`, `xoxb-/xoxp-`, `Bearer `) over the trace slice + page-table texts; pass = 0 hits |

The memo's three DQ names (`replayDeterminism`, `pinLint`, `redactionScan`) map 1:1; `sourceFidelity`
is added because the verify relay was cheap to compute and is the check a receiver runs anyway.

## 4. KPIs (v0 formulas pinned; UC3 target values recorded)

`kpi-fault-recall` = faults recorded at turn ≤ N whose page is Full at N ÷ faults ≤ N (null when no
faults) · target 0.95. `kpi-net-token-reduction` = stubbedTokens ÷ (resident + stubbed tokens) at N
— the v0 stub-cost fraction (policy-vs-policy net cost is UC3 work) · target 0.40.
`kpi-touch-ratio` = distinct pages with a recorded full render ≤ N ÷ the declared slot roster
(null when empty) · target 0.60. All three carry their formula strings in the manifest so a
receiver never has to guess the v0 semantics.

## 6. Limitations & notes

- `redactionScan` is pattern-based hygiene, not a redaction review — scoped to credential-shaped
  tokens; the unique dimension label follows UC3's naming.
- `kpi-net-token-reduction` is slot-math on the snapshot (stub-cost fraction), not the ≥1.5×
  policy gate — that measurement class is UC3's.
- The memo's corpus-level packaging row (`export --odps corpus/... --tag …` producing one
  versioned data product, RR-UCVERIFY row 4) remains DESIGN-CONCEPT — this card ships the
  single-session handoff snapshot only.
- Cross-card note: T17.1 (`ab62a83`) landed without a LOG/HANDOFF row (its owner's bookkeeping);
  flagging here so the ledger stays complete.
- The on-disk package is v0-honest about remote validation: the ODPS SDK is not run against
  `manifest.yaml` (it validates the committed corpus product); the round-trip gates are the enforced check.
