**Echo anatomy** (one user message: read → re-read → edit → fresh read → missing file):
`page.declare` alpha → `identifier_scan` fault turn 0 → double fetch `tool_recall` fault
turn 1 → edit declares its own page → post-edit read lands a **new contentHash** as a
second `page.declare` (fresh fetch, never scored waste) → the errored read produces no page
(`status:"error"` dropped per T6 §2). 5 tool pairs, 4 completed + 1 errored.

**Thrash anatomy** (5 rounds × 5 files, 25 reads, all completed): 5 page declares,
5 `tool_recall` + 5 `identifier_scan` faults, `call.meta` shows the resident set
(289 tokens) hit at every later turn. This is the **pre-eviction** thrash shape: v0 has
no eviction path, so no `page.evict`/stub rows can exist; the synthetic P-pathology vector
in `corpus/m1/` remains the eviction-shape reference. Documented in provenance limitations.

## 3. Contract findings (v2.1.2 runtime vs T9 pin v2.1.3)

- The v1 docs form (`export const X = async (ctx) => ({ "tool.execute.before": … })`) is
  **rejected** by the v2.1.2 loader: “Plugin must export a default definition with an id
  and an effect or setup function.” Ground truth found in pinned source
  `packages/core/src/plugin/module.ts` (`@ e965774f`): the accepted module is
  `{ default: { id, setup } }`; the promise adapter (`@opencode/plugin/promise`) exposes
  the domain hooks.
- `ctx.session.hook("context")` fires **only for primary model requests** (title/
  compaction/generate use their own hook names) — the T9 “one fire = one turn” fact holds.
- Observed payload fields match the T9 pin for both tool hooks (`tool, sessionID, agent,
  messageID, id, input [, status, result|error]`). `SessionContext.model` is
  `{ id, providerID, variant }` on v2.1.2, not `{ providerID, modelID }` — metadata only;
  the mapping reads `sessionID` + `messages`.
- Message texts live in `content[].text` (user/assistant); tool-result parts carry no
  `.text`, so the T9 `transcriptTexts()` sees transcript material only.
- `session.idle`/`session.status` were **not emitted** by v2.1.2 in these runs; plugin
  cleanup runs on `location.shutdown`, which is the flush point used here.
- Local plugin imports resolve with Bun: absolute repo paths and relative TS imports both
  verified; no bundler step needed.

## 5. Honest deviations / limitations

- **Binary version:** captured on v2.1.2, while T9 pinned contracts at v2.1.3 `e965774f`.
  The observed diff is metadata-only (`SessionContext.model` field names); documented in
  `corpus/m2/provenance.json` and the adapter README.
- **No eviction:** v0 is declared ⇒ resident; the live thrash drop demonstrates sustained
  re-fetch pressure, not page-out/stub dynamics. The P-pathology vector stays the eviction
  reference until paging ships.
- **Fault dedupe:** the tracer emits one fault per page·source, so repeated re-fetches of
  the same page show as one `tool_recall` row each; per-turn pressure is visible in
  `call.meta`.
- **Model determinism:** beats were induced with an explicit step-by-step prompt and
  captured in one run each (no retries). The mapping is deterministic; the model output
  is not — that is the difference from M1's synthetic references.
- **budgetTokens=200000** is the T9 fixture convention (declared headroom bookkeeping),
  not the provider's measured window.
- Session workspace (`/tmp/opencode/t12/...`) is disposable and not committed; the
  committed artifacts are the adapter, its README/test, and the corpus drop.
