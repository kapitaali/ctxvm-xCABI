   the command says `N trace(s) flushed` or `0 traces written — no events were captured between

   flat keys and the nested `model: {id, providerID}` shape, env as fallback.

`/ctxvm-trace status` now prints the resolved absolute dir **and its source**; `PLUGIN_VERSION`
and `plugin.yaml` are 0.3.0 so a stale running copy is identifiable from its own output.

**Write-through, then retention, then a byte budget.** The first capture was written once, at the
end, so a crash lost the session; nothing bounded the directory. Write-through persists
`<file>.partial.jsonl` every N units of activity and a complete flush deletes the partial **before**
writing the final pair, so a partial can never be mistaken for a capture. Retention prunes
oldest-first, never the file just written. One honest divergence is documented rather than hidden:
the cadence is per **event** in hermes (its adapter can see the tracer's event list) and per **hook
fire** in opencode (its plugin hides that list behind `finishAll()`).

The next commit closed the gap the previous one had named out loud: retention was age- and
count-based, so a directory of huge captures under the file cap was still unbounded. The byte budget
defaults to 512 MiB and counts the file just written against the total. Still not claimed: sidecars
and the witness log do not count, and pruning happens at flush time only.

**The reading.** TokenEconomizer (arXiv:2610.22732v1) cuts agent cost 18.4–30.9% at comparable
Pass@1, and the largest mechanism is tool pruning — 23 schemas load every turn, no repository calls
more than seven. It does this **without any context virtualization**, which is the uncomfortable part
for us: our capture reported waste 1.000 on 268 tokens, degenerate precisely because the cost that
mattered was billed every turn and never touched. The same section records the X post's "90% → 4%"
fabrication figure as **UNVERIFIED** — the cited paper's abstract contains no such numbers — and
notes that the post ends with a Telegram link.

**The prompt, then the implementation.** W13–W16 went into `08.1-UPDATE-PROMPT.md` in the order the
gaps bind, each with its evidence locator and acceptance test, plus a line in §9 that now reads:
do not claim ctxvm reduces token cost — no saving has been measured on our data, and W13–W16 make
the saving *measurable*, not achieved. Then W13 itself: `turn.render` gains an optional `prefix`
(`toolSchemas`, `messageCount`, `requestChars`, `systemPromptBytes`, `approxInputTokens`, and a
required `source`), filled from hermes' `pre_api_request` payload and honest-reported as `unknown` by
opencode. Version-gated, allowlisted in the strict codec, three validator negatives, conformance
vector updated.

**Three things the gate caught that I would have missed.** `ts` must ride last, so the field goes
before it in all three emitters — the ts-last pins caught two of them, and the Rust struct's
declaration order decided the canonical bytes. The ai-sdk canon had to be regenerated, because its
generator deletes every `CTXVM_*` var including the `CTXVM_TRACE_TS=0` its own replay pin needs. And
a background gate run that reported failure arrived *after* the fixes — it was the pre-fix run still
in flight; the authoritative gate is the one that ran afterwards.

## 11. Later — W14: an environment key, so sessions form a stream

W13 made cost visible per turn; W14 makes it comparable **across sessions in one repository**. The
paper's unit is a task stream in an environment — repeated setup, re-read files, savings that appear
by the sixth task — and our ledger had per-session identity only.

`session.open.environmentId` is `env-` plus 12 hex of a SHA-256 over either the credential-stripped
git remote or the worktree path. Only the digest is emitted: no path, no remote, no branch (branch
names change per task and can name a client). opencode and ai-sdk derive it from the project
directory. **Hermes does not, and that is the honest outcome**: the plugin runs inside the gateway
process, whose cwd is the gateway's, so a hash of it would give every session one fake environment.
That lane emits an id only when an operator registers one, and a malformed value is dropped rather
than coerced.

Byte-stability detail worth keeping: fixtures pin `env-000000000000` instead of deriving, because a
hash of the CI runner's checkout path would differ per machine and break a byte-identical test for a
reason unrelated to the code.
