## Survey facts the design is built on (probed 2026-10-28, read-only)

- **The mutation reach is pinned, not open**: `design/adapters.md` (pinned
  upstream `e965774fa`, v2.1.3) — `prepare("primary", …) →
  hooks.trigger("session","context",{ ...draft, agent, tools })`; payload
  `SessionContext extends SessionRequest` with **mutable `messages`**; the
  shallow spread shares the array references, so a prepend reaches the live
  draft.
- **One `session.context` fire = one model request = one xCABI turn** — boot
  injection = the FIRST fire of the resumed session, exactly once.
- **The m6 knowledge-stateful tail law** (residency derived from the real
  context) made capture order a real question → ruled inject-then-capture.
- **The plugin shim models the payload readonly** — the gated mutation is a
  controlled escape from the readonly view, never a type accident.
- **No `CTXVM_FEATURES` vocabulary existed in opencode live** — the gate
  check mirrors the hermes `parse_features` law's shape (comma/whitespace-
  separated, case-insensitive, unknown tokens ignored).
- **The boot law was already in place**: `CTXVM_RESUME_FROM` →
  `resumeVerify` BEFORE hook work (B3 + m7 law); injection arms only off a
  VERIFIED boot — inject never rescues an unverified one (byte-pinned).
- **`resumeVerify` fail-closes every structural shape** the arm could hit
  (malformed page-table → `page-table unreadable`) — the arm's catch is
  defense-in-depth; the reachable never-breaks pin is a HOSTILE payload.

## Disclosed

- **The `system` surface is NOT metered by the v0 transcript view**:
  `transcriptTexts` reads `payload.messages` only (the RFC-0 scan law), so
  the injected brief rides OUTSIDE the metered projection — the Q4 order is
  still ruled and implemented (inject strictly precedes the capture read,
  pinned via witness order), but with the system surface the honest trace
  statement is: the trace meters the native conversation; the injected
  context's provenance lives in the witness log + the `resumeFrom` sidecar
  evidence. A messages-surface variant (metered, fake-turn risk) is the
  recorded v-next alternative.
- **No corpus drop**: the m6/m7 README law "Resume is observation, not
  injection (v0 §3)" stays true for every SHIPPED package — all shipped
  corpora are observation-shaped; T25 ships the CONTROL PATH only, exercised
  by synthetic-payload tests.
- **Hermes stays verify-only** (5 observed hooks, no context-mutation
  surface) — their `/ctxvm-resume` UX is the design's lawful fallback,
  landed on their lane 2026-10-28. No hermes files touched.
- **Tracer stays read-only in every path** — the plugin mutates the draft,
  the tracer only meters it (design risk 5's mutability temptation stays
  fenced at the module boundary; the tracer core untouched).
