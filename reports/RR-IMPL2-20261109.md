## 1. What `ledger_tools.py` implements (`umpire/spec/ledger_tools.py:1-118`)

- `canonical_json` (21-23): `json.dumps(sort_keys=True, separators=(",",":"), ensure_ascii=False)`.
- `hex8/content_hash` (26-32): `sha256:<8 hex>` of UTF-8.

- **Line validation:** NOT in `ledger_tools.py`. It lives in `umpire/spec/validate_ledger.py` (592 lines): jsonschema vs vendored `spec/vendor/x-cabi-0.1.schema.json` + decision-record schema, minting recomputation, 14 engineered negatives (PASS 130 checks, §2.5 command). `ledger_tools` only derives page table (`derive_page_table` 70-113).

- **File/ref helpers missing:** no `fileRef`/`summaryRef`/`imageRef`/`identityTokens` equivalents (cf. `packages/node/src/ident.ts:51-79`).

TL;DR: minting = canonical + hash + decide_ref + approx4 + response_hash + 120-char truncation, byte-compatible with `ident.ts` for ASCII-only (00-SPEC.md:63-66).
