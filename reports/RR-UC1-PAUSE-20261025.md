### 2.2 Pause module — `packages/hermes/src/uc1_handoff.py` (REPLACED stub)
`UC1Handoff.pause(trace_dir, turn=None, handoff_name=None)`:
1. Flushes live tracers to `trace_dir` (existing flush path, `CTXVM_HANDOFF_DIR` override)
2. Era-snapshots the flushed file (`{name}-turn-N.{jsonl,meta.json}`, cp -n never clobbers)
3. Packages via `export --turn N --output <dir>/handoff/ --odps`
4. Runs replay counterproof on `trace-N.jsonl.zst` (best effort, never blocks)
5. Returns `{"exit_code", "snapshot", "report", "stderr", "verified", "divergences", "witness"}`

`UC1Handoff.resume(snapshot_dir)` is a B3 stub returning exit 2 with a guidance message.
All hook handlers (`on_session_start`, `on_pre_tool_call`, `on_post_tool_call`,
`on_pre_llm_call`, `on_session_end`, `flush`) are no-ops in the pause beat.

### 2.3 Slash command — `packages/hermes/live/__init__.py` (MODIFIED)
`/ctxvm-handoff <dir> [turn] [--stop]` registered only when `CTXVM_FEATURES=handoff`:
- `<dir>` — flush/pause target (or `CTXVM_HANDOFF_DIR`)
- `[turn]` — handoff turn (default: flush at current turn)
- `[--stop]` — stop tracing after packaging

Prints packaged export JSON + `ctxvm-handoff: exit_code=... verified=... divergences=...`.

## 4. Deviations from card/design

- **Pause trigger:** design says env-first (`CTXVM_HANDOFF_DIR`), slash as sugar. Implemented exactly
  that way — slash command reads `trace_dir` from argv or falls back to `CTXVM_HANDOFF_DIR`.
- **Pause = flush at current turn unless `--turn` given:** implemented. `CTXVM_HANDOFF_TURN` env
  also honored as a fallback for `turn`.
- **Resume (B3) is a stub:** `resume()` returns exit 2 with guidance, as designed
  ("resume = verify-first + provenance" is beat B3, not B2).
- **Injection (handoff-inject) is NOT in this beat:** parked as opt-in per design §1.3.

## 5. Discoveries

- The `export` binary's `--odps` flag produces the full memo-specified artifact set
  (`manifest.yaml`, `llms.txt`, `trace-N.jsonl.zst`, `page-table-N.json`, `checksums.sha256`)
  — verified live against `corpus/m2/live-echo.jsonl` during the design pass (RR-UC1DESIGN).
  The pause module packages that same output.
- Replay counterproof on `trace-N.jsonl.zst` confirms byte-identical re-render at the
  pause turn (exit 0, divergences []), satisfying the fact gate before resume.
