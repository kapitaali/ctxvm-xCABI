## W18: monitor replay, tier 1 — a working harness and three nulls

`benchmarks/metrics/monitor_replay.py` (card #3 in the synthesis). A monitor is a pure function of a
trace, so tier 1 scores declared detectors over the frozen corpus with no model calls: two runs must
agree byte for byte, and `--check` fails when the committed results drift. Thresholds were declared
before scoring.

The labels are **scenario** labels — healthy, echo, thrashing, recall, pause/resume — with the cited
sentence for each. The corpus contains no sabotage, so the harness measures a pacing pathology, not a
safety monitor, and the fault-derived rule is marked `diagnostic` because its feature shares a cause
with the thrash label.

n=17 (4 positives, 13 benign). `fault_density` TPR 0.500, FPR 0.308; `waste` 1.000/1.000 with no
dynamic range; `token_pressure` 0.000/0.000 because the highest capture reaches only 40.1% of its
budget. The sharpest finding is a confound: benign `corpus/m5` runs 1.214 faults per turn, higher
than two of the four labelled thrash traces. Fault counts are not a pathology proxy.

So the harness is the deliverable and the labels are the gap. Tier 2 — interventions outside the
core, marked non-deterministic — is what would give it something to measure.

## W19: the tier-2 boundary, written before the code

`design/W19-tier2-interventions.md`, design note only. Tier 1 is byte-identical over recorded bytes;
tier 2 runs a model with one thing changed. The argument of the note is the boundary: a tier-2
artifact never enters the deterministic namespace — not `corpus/`, not a shared checksums file, not a
shared claim — because a counterfactual copied there makes the next determinism check certify a
non-deterministic object.

The run record is a sidecar with four non-optional fields (parent digest, intervention target,
sampling, model identity) and `nonDeterministic: true` as a literal. Three experiments are
preregistered with arms, metrics, materiality rules and kill conditions: hint injection with the
channel comparison; page ablation against the touch ratio, which is the only operational test of what
a fault means, since "needed" is defined as "removing the page changes the answer"; and eviction of an
early wrong premise with an oracle arm, without which the result cannot separate help from harm.

Implementation is owner-gated on model spend, and the first card must measure cost on one task before
any larger run.

## TS order: the test asserted an invariant the wire does not have

The gate went red on the docs-only W19 commit, and the cause was a test, not the wire: `finish()`
emits the tail grouped by class (every `turn.render`, then every `call.meta`), both carrying that
turn's render stamp, so the tail sequence is `[s0..sN, s0..sN]` and is monotonic only while a run fits
inside one millisecond. The 11-03 fix had replaced one clock-luck assertion with another, which is why
that flake never went away. Both lanes now assert what the code has: live prefix non-decreasing, tail
grouped by class, turn stamps ascending, and each `call.meta` carrying exactly its render's stamp.

Also recorded: the W19 commit landed with a red gate because `bash tools/run-ci.sh | tail -2` returns
`tail`'s status. The gate is now run unpiped with its exit code captured.

## W20: four extensions, priced and not built

`design/W20-trace-surface-extensions.md`. Four proposals under one constraint: RFC-0.1 is additive, so
each is a field, a sidecar, or a refusal to proceed.

Refusals have no representation today — a decline looks like a turn with no declares — and the honest
difficulty is that `turn.render` is stamped at render while a refusal arrives after the response.
Provenance needs three attributes (`origin`, `trust`, `readers`) and the rule that absence never reads
as trusted. Paging gets a threat model with three mechanisms, including re-fetch laundering, where an
evicted attacker page returns carrying a fresh `tool_recall` fault that looks legitimate. Tamper
evidence gets four priced options, from a hash chain (a field per event, a v0.2) to a signed Merkle
root, with the recommendation that unsigned traces are only as trustworthy as their directory.

Every row ends in an owner decision, and none is implemented.

## W21: a reused name can no longer replace another session's bytes

`RR-W21-20261105`. The rule the 13:00 incident argued for: before a flush writes, it reads
`<file>.meta.json`, and a different session id gets `<file>-<sha256(sessionID)[:8]>` with the same
suffix on the meta and coverage sidecars. The same session keeps its name, so a re-flush stays
idempotent. The retention `keep` guard and the manifest's `traceFile` follow the resolved name — with
a suffix, the base name would leave the just-written file unprotected.

Three lanes, three tests, and the W17 checker still accepts the suffixed pair. hermes 119, opencode
62, ai-sdk 46. No wire byte changed: naming is a harness concern.
