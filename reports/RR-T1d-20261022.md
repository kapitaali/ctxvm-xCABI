# RR-T1d — Replay engine + divergence detection + `replay` CLI

**Card executed:** T1d (M) · **Date:** 2026-10-22 · **M0 gate reached**

## What was done

- `ctxvm-core/src/replay.rs` — `replay(trace)` static analysis:
  - feeds ALL decision events through `Playback` (final-schedule semantics), then
    checks every fact event against it
  - divergence kinds: `RenderModeMismatch{turn,page,inferred,recorded}` ·
    `RenderOfUnknownPage{turn,page}` (fact referencing a never-declared page) ·
    `ResidentTokensMismatch{turn,inferred,recorded}` (`turn.render` cross-check)
  - `ReplayReport{events, divergences, violations}` — violations ride along as
    telemetry; ONLY divergences drive the exit gate per `03` CLI notes
  - comparison semantics documented in-module for RFC-0: final-schedule static
    analysis; `turn.render.evictedTokens` recorded but unchecked in v0 (stub sizes
    need a tokenizer — flagged)
- `ctxvm-conformance` (now depends on core + serde_json):
  - **`vectors/session-clean.jsonl`** — 22-line green-path mini-session: 3 declarations,
    render-facts for turns 0–3 across an evict@1/fault@2 cycle, consistent
    `turn.render` tallies, closing `call.meta`. Zero divergences, zero violations.
  - **`vectors/session-divergent.jsonl`** — same session with two engineered lies
    (resident-total lie at turn 1; rendered-stub lie at turn 3).
  - 4 replay conformance tests (clean/2-divergence/report-determinism/corpus-parse)
  - **`src/bin/replay.rs`** — thin CLI: `replay <session.jsonl>` → JSON report stdout,
    exit 0 clean / 1 divergences / 2 usage-IO-parse (per `03-tracer-api-ts.md`)

## Deviations from card

- The card said "compare against expectation embedded in trace (final renderTotals)" —
  implemented as full fact-checking (both `page.render` modes AND `turn.render`
  resident totals), not just final totals. Small scope extension, same intent.

## Discoveries

1. The T1b codec vector corpus (`events-v0.jsonl`) is intentionally NOT replay-consistent
   (turn.render totals are codec fixtures, not engine semantics) — kept in codec-land
   only; conformance now has purpose-built replay fixtures. Fixture taxonomy: codec
   vectors (byte identity) vs replay fixtures (fact coherence).
2. Exit-code contract (0/1/2) fixed now so T2/T5 doc surfaces can reference it;
   violations never trip exit 1 (they are decisions-policy telemetry, not coherence
   failures).
