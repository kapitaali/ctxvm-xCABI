# RR-T1b — Event model + strict JSONL codec + golden vectors

**Card executed:** T1b (M) · **Date:** 2026-10-22

## What was done

- `ctxvm-codec` implemented:
  - `model.rs` — all 9 event verbs as an internally-tagged serde enum (`tag = "type"`,
    tags verbatim dotted form from 02); `PageId{logicalRef, contentHash}`, `PageRef`,
    `PageKind`, `RenderMode`, `FaultSource`, `CacheEstimate`; camelCase fields,
    snake_case enum values, zero floats (u64 tokens only)
  - `jsonl.rs` — canonical JSONL reader/writer (compact, declaration-order fields,
    trailing newline, blank lines skipped on read) + `CodecError{line, message}`
    with accurate 1-based line numbers
  - **Strictness layer (important):** serde's internally-tagged enums silently DROP
    unknown fields, which would quietly rewrite traces. The codec pre-checks every
    line against a per-tag field allowlist before model deserialization → unknown
    type, unknown fields, missing fields, and float-encoded token counts are hard
    errors. This is a determinism-required deviation from vanilla serde behavior.
- `ctxvm-conformance` wired against the codec:
  - `vectors/events-v0.jsonl` — 10-line golden corpus hand-authored in canonical
    form (all 9 types; evict carries the **verbatim stub text incl. embedded newline**
    from 02; call.meta carries `providerReported:false`)
  - `vectors/README.md` — canonical-form rules + line-by-line coverage table
- Workspace dep graph: `ctxvm-codec` → serde/serde_json; `ctxvm-conformance` → codec.

## Deviations from card

- Strictness implemented via allowlist pre-check rather than `deny_unknown_fields`:
  serde ignores that flag for internally-tagged enums. Documented in code + vectors
  README; the JSON Schema (T4) will re-encode the same rule as
  `additionalProperties: false`.
- `call.meta` carries an added `turn` field (draft table didn't list one) — without
  it, cache estimates cannot be joined to a turn (breaks invariant 5).

## Discoveries (feeding T4 RFC-0)

1. **Needs a version field before RFC-0 freeze:** nothing in `session.open` models the
   xCABI format version — schema evolution is otherwise impossible. Proposal: `xcabi: "0"`
   top-level in `session.open`; NOT added yet (spec fidelity first).
2. `page.pin`/`page.unpin` intentionally have no `turn` (working-set decisions persist
   across turn boundaries) — must be stated explicitly in the RFC.
3. Optional-field policy locked: **omit, never null** (`skip_serializing_if`) — nulls
   are an ambiguity channel for consumers.
4. serde's silent unknown-field drop is a real corpus-rewriting hazard for any naive
   tagged-enum binding — TS/Py bindings must replicate the allowlist gate exactly.
