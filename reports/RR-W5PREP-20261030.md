## 2. The validity rules (why they matter)

- **Fresh session per harness, same `task.md` text in both, no cross-hints** — the
  experiment compares trace SHAPES for one identical task; "helping" one side breaks it.
- **OpenCode first, Hermes second; a failed run documented = a completed run's equal.**
- **Turn units differ by design** (hermes USER-turn vs opencode model-request, W4 F2):
  W5 must classify these as UNIT MISMATCHES, never behaviour.
- **No corpus drop from these captures** — they are working evidence; any drop follows
  the standing corpus rules (redaction scan, provenance, checksums, gates).

## 3. What happens after the two captures exist

1. `./rust/target/release/diff /tmp/ctxvm-w5/w5-opencode.jsonl /tmp/ctxvm-w5/w5-hermes.jsonl --output /tmp/ctxvm-w5/diff.json` — raw report kept as evidence.
2. Normalization of legitimately non-deterministic fields (ids, provider latencies) happens in the W5 analysis, outside `diff`.
3. `node tools/waste-report.mjs` over both captures — the **W1 live run piggybacks** here.
4. The W5 card classifies every divergence (harness behaviour vs adapter bug vs spec ambiguity), feeds spec ambiguities into W7, and updates `01-PLAN.md` milestone wording with owner approval.

Note the deliberate timing: because of W4b B1, this is the **first cross-harness run
with a live Hermes `identifier_scan` surface** — the m4/m7 dead-surface limitation no
longer applies to new captures.

## 5. Deviations / open questions

- The OpenCode model default is the free-tier `opencode/glm-5.3-flash-free` and Hermes'
  model is left as `<provider/model>` — the owner may pin any model per side; W5
  compares trace shapes, and the price model (W3) keeps provider/estimated tokens
  separate, so cross-provider is honest. No requirement that both sides run the same
  model — recorded here so the asymmetry is chosen, not discovered later.
- The owner-run window is unscheduled; nothing else in the queue is blocked by it
  except W5 execution itself and B2 (which the owner queued immediately after W5).
