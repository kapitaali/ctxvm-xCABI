### B0 — re-pin survey + ERRATUM (`design/adapters.md`)

Adapter B was written against `vercel/ai` main @ `36e4ce7c`. Re-surveyed the
latest stable tag `ai@7.0.154` end to end at the pin: **no hook-point drift** —
all five surfaces (middleware `transformParams`, fullStream
`tool-call`/`tool-result`/`text-delta`/`start-step`/`finish-step`) survive.
Four formal deltas recorded as an **ERRATUM appended to `design/adapters.md`**
(and bound by the fixtures/tests):

1. Middleware typing is V4-based: `LanguageModelMiddleware` =
   `Omit<LanguageModelV4Middleware,'specificationVersion'>` (dist
   `index.d.ts:158–168`).
2. Preliminary tool results: v7 streams `tool-result.preliminary`; the tap
   skips them (sidecar counter `preliminarySkipped`) and pages only final
   results — page-on-final is the T6 `isError` law keeping its letter.
3. App-layer `text-delta` carries **`text`** (the pinned-commit text says
   `delta`) — fixtures and tap bind to `text`.
4. `providerOptions[<providerName>]` spreads **raw body fields** into the
   provider request (`@ai-sdk/openai-compatible` dist `index.js` ~L102–103) —
   this is how `chat_template_kwargs` rides without any bespoke header work;
   and provider reasoning channels (`reasoning_content`) map to reasoning
   parts, which the tap passes through **unmapped** (thinking is never paged,
   matching m2/m7's reasoning-channel standoff).

Pin ruling: `ai@7.0.154`; `"latest stable"` is the reproducibility contract,
re-verified before the live drop ran.

### B1 — the glue package (`packages/ai-sdk`)

Mirrors T12's adapter pattern, library-shaped (harness story: library + app
author, not a plugin host). Relative imports of `@ctxvm/node` only — the
`packages/node|opencode|hermes` lanes untouched:

- `src/contract.ts` — capture options (agentId/model/provider/budgetTokens) +
  sidecar shape. `sessionID` default `"local"` (library boundary, not a host
  session).
- `src/middleware.ts` — **render anchor**: `transformParams` fires once per
  model call = one xCABI turn; `params.prompt` is the exact outbound window
  (`toResponseMessages` folds prior tool results into it, m2's law). Params
  are returned **unchanged** — the mirror contract has its own
  counterexample-shaped test. Design risk 5 (mutability temptation) is locked
  by a test, not a comment.
- `src/tap.ts` — **fullStream pass-over** (generator, every part yielded
  untouched): `tool-call` → recall *before* the result exists (the T6
  recording matrix applies without buffering, stream order holds);
  final `tool-result` → page; `tool-error`/`tool-output-denied` → denied, no
  page (T6 §2); `text-delta` text accumulates; scan flushes at `finish-step`
  (no-T3-lag: faults attribute to the producing turn); per-step fold into
  `{ session, stepIndex }` keyed matcher state (design risk 2).
- `src/flush.ts` — env-gated finish: `flushTraces()` → RFC-0 JSONL via
  `@ctxvm/node` `finish()` + `<name>.meta.json` sidecar (hookStats +
  `mirrorCountsAgree`).
- `src/index.ts` — `createCtxvmCapture({ agentId, model, provider,
  budgetTokens })` → `{ middleware, tap, finishAll }`; env-gated CTXVM_TRACE_DIR/
  CTXVM_TRACE_NAME as throughout.

Sidecar shape shipped: `{sessionID, harness:"ai-sdk", aiSdkVersion,
captureVersion:"0.1", model, provider, agentId, budgetTokens, capturedAt,
hookStats:{middlewareRenders, tapStepEnds, toolCalls, toolResults,
preliminarySkipped, deniedOrErrors, textDeltas, scannedBytes, steps},
mirrorCountsAgree, traceStats}`. The **counts witness** (middlewareRenders ==
tapStepEnds) is design risk 1 made checkable per drop; a divergence would
taint the sidecar, never mis-score (warn + skip, as designed).

### B3 — live drop `corpus/m8` (free tier, USD 0)

**Lane ruling first (recorded for every future rerun):** the zen gateway is
**BLOCKED for scripted capture** — eyewitnessed 429 `FreeUsageLimitError` for
all three call shapes (bare request; CLI-credential Bearer; client-emulating
headers); the observed success path is the CLI's own client-session gating,
which a scripted `streamText` loop cannot enter. So the T15 free-tier lane is
**NOT zen** — the operator supplied an NVIDIA API key, and the lane is
`https://integrate.api.nvidia.com/v1` via `@ai-sdk/openai-compatible`, model
**`nvidia/nemotron-3.5-super-vl-120b-a12b`** (operator's pick; present in the
85-model catalog), thinking **off** per beat via
`providerOptions: { nvidia: { chat_template_kwargs: { enable_thinking: false } } }`
(the raw-body-spread fact, erratum 4). Key hygiene: the key lived in a 0600
file, read per-invocation, never echoed, absent from every trace/sidecar/log;
**the operator should rotate it after push** (it transited chat in plaintext).

Probe receipts before the drop: streaming probe 76 chunks (32
`reasoning_content` deltas + 4 `content` deltas, usage 1186 prompt / 119
completion tokens); in-package preflight through the REAL adapter — 2 turns,

## Discoveries / record

1. **Erratum set** (design/adapters.md, bound by tests/fixtures): V4 middleware
   typing; `tool-result.preliminary` (skipped, counted); app-layer
   `text-delta.text`; `providerOptions[<name>]` raw body spread (the
   bootstrapping channel for provider-only request fields).
2. **Thrown vs body error tiers split the T6 §2 law:** error-*shaped* result
   bodies page (they are results); thrown errors become v7 `tool-error` parts
   and page nothing — datasets that want the "no page" story must throw. m8
   demonstrates both tiers in one trace.
3. **Model-string law for namespace-bearing catalog ids:** use the provider's
   id verbatim; do not re-prefix (`nvidia/nvidia/…` was caught in canon).
4. **zen free tier is client-session-gated;** scripted free-tier capture lanes
   must pick keyless-API or static-API providers. NVIDIA NIM approved (free,
   key per invocation, catalog-keyed models, `chat_template_kwargs` thinking
   switch per beat).
5. **Determinism split, restated for a library adapter:** the B2 fixtures pin
   the *mapping* determinism (byte-stable); live model output is not
   reproducible — that is what makes m8 a live reference, not a golden one.
