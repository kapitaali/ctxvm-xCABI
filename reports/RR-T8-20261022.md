## Design decisions — verified against the engine, not assumed

1. **Page identity = `(logicalRef, contentHash)` pair.** Confirmed against
   `ctxvm-core` `page_key`: a fresh fetch (same args, new hash) is a SECOND page
   slot, and `DuplicateDeclare` only fires on same-key descriptor mismatch. The
   tracer therefore never re-declares an identical `(ref, hash)` and treats the
   changed-resource landing as a new declaration with no fault (T6 §4 honesty
   row: changed underlying resource ≠ waste).
2. **Turn-level facts flush at `finish()`.** Replay is a *static analysis*: facts
   are compared against the FINAL derived schedule, and `tally_at` sums the whole
   declared table (`mode_at` = Full everywhere with no evict path). An eagerly
   emitted mid-session `turn.render` would `ResidentTokensMismatch` on every
   earlier turn once a later page is declared. The flush batch (`turn.render`
   0..N, then `call.meta` 0..N) also reproduces the reference fixture's shape.
   This is the derived-composition semantics of RFC-0 — a page declared at any
   stream point counts resident from turn 0 in v0.
3. **Fault turn = turn-in-composition at observation; pre-first-render clamps to
   0** (schema: `turn` is `I≥0`). Preserves RFC-0 §5 timing semantics for
   mid-lifecycle recalls (`tool.execute.before` → landing → next `render()`).
4. **`call.meta` = per-turn page-layer estimate** (`estHit` = tokens unchanged
   since the previous composition; `providerReported: false`). Non-page prompt
   text is not tokenized in v0 — RFC-1 parked item.
5. **Name reconciliation:** T6/T7 sketches' `page_raw` / `observe_recall` /
   `scan_text` ship as `page` / `recall` / `scan` (canonical public names;
   documented in the package README).

  the derived tally (documented).
- Zero runtime dependencies; Node ≥ 22.6 type-stripping; erasable-syntax-only TS.
- Rust workspace byte-untouched; reporting-only edits elsewhere.
