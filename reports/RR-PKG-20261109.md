## Versioning policy (proposed, separates schema from package semver)

- Schema version (`spec/rfc-0/x-cabi.schema-v0.json` + RFC-0.1 `schemaVersion`) is **independent** of package semver. RFC-0 stays v0/sealed; RFC-0.1 adds `schemaVersion: "0.1"` negotiation — package `0.1.0` does not imply schema `0.1`.
- Package semver: `0.x.y` for all crates/adapters until first published release, then reset per cargo/npm rules. `ctxvm-py` and Rust workspace share `0.1.0` today — keep lockstep until PyO3 lands.
- Tags: no tags exist (`git tag -l` empty). Release sequence (owner-gated): (1) build + notice files, (2) tag the release commit, (3) publish from tag, (4) submit indexes pinned to tag commit.
