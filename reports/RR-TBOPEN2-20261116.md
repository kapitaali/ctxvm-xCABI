## 3. Phase 1 run

Run bundle: `~/.local/state/ctxvm/w8-runs/tb-open2-20261116/` (fixture, `prompts.jsonl`, `lookups.json`
copied from the accepted phase-0 bundle). No repo code or tool was changed.

```sh
cd ~/.local/state/ctxvm/w8-runs/tb-open2-20261116
SID=ses_tbopen2_20261116_p1d
for n in 1 2 3; do
  timeout 180 opencode run --session "$SID" --model opencode-go/hy4-flash-free \
    --auto "$(cat p$n.txt)" > p${n}d.out 2> p${n}d.err
done
opencode session export "$SID" --sanitize  > export-phase1.json
opencode session export "$SID"             > export-phase1-full.json
python3 ../../../Documents/ctxvm/tools/tb-check.py fixture --per-reply replies.jsonl \
  > per-reply-phase1.txt
```

`--auto` was used so execution tools are available rather than refused. All three prompts exited 0
within the 180 s cap; no tool refusal, no `does not exist` error, no auth error, no billed token.
The harness session `info.cost` is **0**; that is a harness-reported field, not a provider receipt,
so no $0 claim is made.
