## Numbers (reproducible by the commands above)

- Counts: rust **59** default (was 58: −1 T1a placeholder, +2) / **60** with
  `tiktoken`; ts `13 + 58 + 45`; python `80 + 30 + 8`; **ALL GATES GREEN**
  (including the new feature-gate line), witnessed 2026-10-29 pre-commit.
- Sample: `apx4("hello world") = 3` == node `approx4` (byte parity);
  `tiktoken-o200k_base("hello world") = 2`;
  `tiktoken-cl100k_base("αααα αααα αααα αααα") = 16` where `apx4` says 5 —
  real BPE resolves each Greek alpha as its own token while the chars law
  cannot see below the codepoint level; that divergence IS the point of W2.
  Exact-value pins are deliberately avoided in tests: the vocab snapshot is
  tiktoken-rs's, not ours, and a vocab bump must not break the gate —
  structural invariants (deterministic, monotone, empty = 0) are the contract.

## Marking law status (W2's second half)

- **On-trace, already law:** `session.open.tokenizer_id` (identity; counts are
  only comparable within one tokenizer) and
  `call.meta.cacheEstimate.providerReported` (provenance) exist in the v0
  schema, and the codec threads the bool (jsonl round-trip true/false
  permutations green).
- **The gap, recorded not hidden:** every emitter today hardcodes
  `providerReported: false` (node `tracer.ts`, hermes `plugin.py`) — no
  adapter captures the provider's usage object yet. That wiring is **W2b**:
  `packages/node/**` and `packages/hermes/**` are do-not-touch (HANDOFF rule),
  `packages/opencode/**` needs per-card clearance (T25 precedent), and the
  ai-sdk lane is open. The `tokens_source` vocabulary now lives in the rust
  crate for every consumer; the CLI marks its own output `estimated` by
  construction.

## Limitations

- tiktoken vocabularies are OpenAI's. Counting nemotron / other-provider models
  with them is an **estimate in a named vocabulary** — the id records which
  vocab produced the count; it is never a provider number.
- `apx4-char` stays the default backend: every deployed trace was produced with
  it, and a session's tokenizer is fixed at open (switching mid-stream would
  fork count comparability). Real counts arrive per-session going forward.
- No downstream metric changed in this card (profile/diff/export consume counts
  as-is); W3 consumes the marking law.
