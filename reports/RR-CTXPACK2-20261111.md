## 4. The recurring lesson (why this happened twice)

Both overflows had the same shape: **a shared file grew inside the kit's own caps, and the paste
budget — which is not a checker rule, only a paste rule — absorbed the difference until it did
not.** The kit checker never flagged it; only `session-start.sh` did, and the owner felt it first.
The prompt now carries the paste arithmetic (PROJECT + CONTEXT + packet + 4 ≤ 16,384) and the
PROJECT-STATE cap rule, so the next writer knows both numbers before writing.
