## 2. Finding — the test asserts TWO levels; the third is prose

The reviewer's answer specified three levels, in order of strength: **(1) same parsed model, (2) same
derived page table, (3) same replay report** — and the landed test documents exactly that ("the
assertion is deliberately three levels of *parsed* equality — model, derived page table, replay
report"; "A failure here says which level broke: `parsed model`, `page table`, or `report`").

But the code compares **the replay REPORT** for the second level, and the report carries no page
table:

```rust
// rust/crates/ctxvm-core/src/replay.rs:48-55
pub struct ReplayReport {
    pub events: usize,
    pub divergences: Vec<Divergence>,
    pub violations: Vec<Violation>,
}
```

The test's own comment says "Level 2: both derive the same page table (**the report carries it**)" and
its assertion message reads "replay report (**page table**, divergences, violations) differs" — but the
report has no page-table field, so what is actually compared is (events, divergences, violations) and
**no page table is derived or compared at all**. The golden is likewise a report summary
(`order-expected-report.json` = `{"events": 6, "divergences": [], "violations": []}`), and the vectors
README describes it as "what replay must say about each form" — consistent with a report summary, not
a page table.

**What is therefore asserted today:** (1) equal parsed model, line for line ✓; (3) equal replay report
✓ (and both forms equal the pinned summary ✓); the **ts-placement** property (struct form carries `ts`
last, sorted form carries it before `type`) ✓; and a guard against an empty pair ✓. **What is not
asserted:** level 2 — the derived page table.

**The fix is one call and the API exists**: `ctxvm_core::render::derive_projection(events, turn) ->
TurnProjection { turn, slots, tally, violations }` (`rust/crates/ctxvm-core/src/render.rs:54-61`) is a
pure function of the decisions fed, so the two forms can be projected and compared field by field
(`slots`, `tally`, `violations`) for each turn the trace carries — and the projection can then be
pinned in the golden (which would make the golden a page-table expectation rather than a report
summary). The alternative, if the owner prefers a smaller change: correct the two comments so the
message names what is compared ("replay report (events, divergences, violations)") and drop the
"page table" claim from the test's header — i.e. either assert level 2 or stop claiming it. Both the
comment and the assertion message are in the owner's in-flight test file
(`rust/crates/ctxvm-conformance/tests/key_order.rs`, untracked at the time of this check), so the fix
is **theirs to make**; this lane writes no test byte.

## 7. The level-2 patch, DRAFTED (the owner's in-flight test file is NOT touched)

The owner approved the ordering as proposed, and the remaining executable item here is the missing
third level. The API needs no new surface: `TurnProjection` derives `Debug, Clone, PartialEq, Eq,
Serialize` (`rust/crates/ctxvm-core/src/render.rs:52`), and `derive_projection(events, turn)` is
documented as "pure derive from a raw event slice — identical bytes for identical inputs, guaranteed".
Proposed insertion in `rust/crates/ctxvm-conformance/tests/key_order.rs`, inside
`assert_same_semantics`, after the replay-report comparison:

```rust
    // Level 2: the derived page table must match too. derive_projection is documented as
    // "pure derive from a raw event slice - identical bytes for identical inputs, guaranteed",
    // so equal models entail equal tables - but assert it rather than infer it.
    for turn in 0..=a.len() as u64 {
        assert_eq!(
            ctxvm_core::render::derive_projection(&a, turn),
            ctxvm_core::render::derive_projection(&b, turn),
            "{label}: derived page table differs at turn {turn}"
        );
    }
```

Why the range `0..=a.len()`: there is no public `Event::turn()` accessor, and in a well-formed trace
the turn indices are bounded by the event count, so the range covers every turn that carries content;
projections for absent turns are empty and equal in both forms (trivially true), so the assertion's
value comes from the turns that exist. The two comments the owner may also want corrected in that
file — "Level 2: both derive the same page table (**the report carries it**)" and the assertion
message "replay report (**page table**, divergences, violations) differs" — become true once the
assertion above exists; without it, both should be corrected to name what is compared ("replay report
(events, divergences, violations)") and the header's three-level claim dropped.

The file is the owner's in-flight work (untracked at the time of this check), so this lane writes no
