## 1. Scope — exactly what GO authorized

- A **sidecar assertion record**, placed with a drop's existing `provenance.json` / `checksums.sha256` pair.
- A **stage LIST** per `design/redaction-block.md` → heading **"Required properties", item 1**. That document
  has no numbered sections, so cite the heading and never a position: this line previously read `§4.1`, which
  does not exist — the kind of positional citation the repo's own law warns against.
  Entries are `capture`, `flush`, `export`, each carrying `policyId`, `ruleSetVersion`, `stage`,
  `replacedFieldCount`. One artifact may be redacted more than once, so the list is not a single flag.
- An **explicit consumer rule**: absence of the record means **UNKNOWN**, never "none". A consumer must say
  "redaction unknown" when the block is absent; the v0-era corpus predates any block, so absence is provably
  not evidence of no redaction.
- A **declaration-only enum** for how `logicalRef` was treated — `raw`, `keyed-hashed`, `dropped` — with `raw`
  as the shipped declared value. A declaration is a claim about treatment, not an emitter.

## 4. The consumer contract — exact strings, asserted in the gate

Prose is not a contract until a gate can fail on it. The implementation must print, and the gate must assert,
exactly these forms:

| case | printed | exit |
|---|---|---|
| **block absent** — including every frozen v0-era drop (`m1`–`m8` carry no sidecar) | `redaction: unknown` | 0 |
| **block present** | `redaction: declared`, then one line per stage `stage=<capture\|flush\|export> policy=<id> rules=<version> replaced=<n>`, then `logicalRef: <raw\|keyed-hashed\|dropped>`, then `channels modelled: logicalRef` | 0 |
| **declaration contradicts the bytes** — the block declares `keyed-hashed` or `dropped` while the trace still carries raw refs | `redaction: inconsistent — declared <value>, <n> raw refs present` | **1** |
| **block unreadable or missing required fields** | `redaction: invalid — <reason>` | **2** |

Three assertions the gate must make on that output:

1. the absence case prints `redaction: unknown` and **never** the word `none`;
2. no line contains `verified`, and none asserts that the artifact *is* redacted — the strongest true sentence
   remains *"the `w8-dq-v1` pattern list found zero matches"*, printed as such;
3. the contradiction case exits non-zero and names both the declared value and the observed raw-ref count.

Assertion 3 is the trap made mechanical: a declaration and the bytes are different facts, and a consumer that
prints "declared keyed-hashed" beside raw refs without flagging them has turned an assertion into a false claim
of handling. It is a **lint-level** finding — no verifier, no chain, no canary behind it.

## 5. Fixtures the implementation must ship

- a fresh, non-frozen drop with **no** block → `redaction: unknown`;
- a drop with **two** stages (capture + flush) → both stage lines, each with its own count;
- a drop whose block declares `keyed-hashed` while its trace carries raw refs → `redaction: inconsistent`,
  exit 1 — the negative fixture the contradiction rule needs;
- a **frozen-drop write attempt** (`corpus/m1`) → refused, and no committed byte changes.
