# RR-W22CI-20261116 — the gate covered nothing in `packages/deepseek`; now it covers one file and says so

Owner-directed, hermes-lane card: `tools/**` is this lane's, and the false green it was producing is this
lane's defect, not the dsh lane's. The reviewer's check of the adapter is folded in as the statement of what
the step does **not** cover.

## 1. The defect, measured before it was fixed

| Claim | Check here |
|---|---|
| the gate never runs the adapter's tests | `grep -c deepseek tools/run-ci.sh .github/workflows/ci.yml` → **0, 0** |
| the package is landed | `git log --oneline -- packages/deepseek` → `9a87ba2 W22 Phase 1: land @ctxvm/dsh adapter` |
| page-table cannot even import | `node --test packages/deepseek/test/page-table.test.ts` → `ERR_MODULE_NOT_FOUND: Cannot find package '@deepseek-ai/schemastery'`, pass 0 |
| the integration test never runs | `node --test packages/deepseek/test/replay.test.ts` → `pass 0`, `skipped 1` (needs `CTXVM_TEST_TRACE`) |
| the tree's workspace link is hand-made and absolute | `readlink packages/deepseek/node_modules/@ctxvm/node` → `/home/theb/Documents/ctxvm/packages/node` |

So every "ALL GATES GREEN" this lane printed after 2026-11-15 described a tree whose new adapter was
uncovered — the same false-green class as a gate that skips a step, and worth a card rather than a note.

Reworded per the reviewer and adopted here: **the gate does not run the adapter's tests.** The tests exist
and pass when called by hand (5/5 at `event-map.test.ts`).

## 2. What landed

`tools/ci-deepseek.sh`, called from `tools/run-ci.sh` gate 2 after `check-node-build.sh` (it needs
`packages/node/dist`):

- **creates the workspace link itself**, `ln -sfn ../../../node` — relative, computed from the package, so it
  holds in any checkout. A gate must not depend on a hand-made absolute symlink, and a fresh clone has none.
- **runs one file explicitly** — `test/event-map.test.ts` — and prints, on every run, the two files it does
  **not** cover and why: `page-table.test.ts` needs `@deepseek-ai/schemastery` (private registry, `npm install`
  E404), `replay.test.ts` skips without `CTXVM_TEST_TRACE` and no fixture is tracked.
- **fails on a skip and on a low count**, not merely on exit 1: a gated file that runs 0 tests, or reports a
  skip, is a coverage regression. `rc=0 with the step` proves nothing if the step silently skips.
- prints `pass/fail/skipped` and the minimum it expects (5), so the count it ran is in the log.

## 3. Proof that it can fail (red-before, each restored byte-identical)

| Probe | Mutation | Observed |
|---|---|---|
| P1 | one failing test appended to the gated file | **exit 1**, `FAILED — node --test exited 1`, the failing test named |
| P2 | gated file set to the skipping `replay.test.ts`, minimum lowered to 0 | **exit 1**, `FAILED — 1 gated test(s) SKIPPED; a skip is not a pass` |
| P3 | `rm -rf packages/deepseek/node_modules` | **exit 0**, `OK — 5 passing`, link recreated as `../../../node` |

P3 is the fresh-clone case the reviewer could not get past: with no link at all, the step builds the one the
package needs and the tests run. The absolute link in this tree is now replaced by a relative one on every
gate run.

Gate: `bash tools/run-ci.sh` unpiped, `CTXVM_*` cleared → `ts suites green (24 + 62 + 46 + **5** tests);
python suites green (207 + 8 + 66 tests)`; `ALL GATES GREEN`. The count is derived by `run_counted`, not
edited into a line.

## 4. What is still not covered, and who owns it

- **page-table and replay remain ungated.** Option (ii) — an injectable schema factory, so the page-table test
  does not need the private package — is a source change in `packages/deepseek/**`, which the **dsh lane**
  owns. Until it lands the interim scope stands, and the step names both files on every run rather than
  letting a green gate imply coverage.
- **Option (i) is impossible**, per the reviewer's fresh-clone check: `npm install --omit=peer` in the package
  returns E404 on `@deepseek-ai/dsh-type-meta`. Not reproduced here (it needs the network); recorded as the
  reviewer's finding, not this lane's.
- **A tracked fixture for `replay.test.ts`** would turn a skip into a run. Not done: it needs a trace small
  enough to commit and free of redaction risk, which is a corpus question, not a gate one.
- **(B) tsconfig coverage** — type-checking the package — is a separate, later step; the reviewer's point that
  it would not have caught these two failures holds.
