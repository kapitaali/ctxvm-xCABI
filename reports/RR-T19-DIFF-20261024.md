## 1. What this card added

### ctxvm-core (1 new module, 4 new unit tests; 20 → 24)

- **`diff::diff_traces(a, b)`** — positional comparison over **decoded events**
  (structural identity; file-level key order/whitespace is not identity):
  - `commonPrefixEvents` — length of the identical leading run.
  - `relation`: `identical` · `bExtendsA` (the UC1 handoff expectation — b = the
    original region + new events) · `aExtendsB` · `divergent` (disagreement
    inside the shared length, with `firstDivergentEvent` = the 0-based index).
  - Page-level state delta: `pagesDeclaredOnlyInA/B` (full identity), the
    **divergent-hash class** (same logical_ref, disjoint content_hash sets —
    the M1b A/B shape), and `tallyMismatches` (derived resident tokens at
    common `turn.render` facts, replay's end-schedule semantics).
  - `aLastTurn`/`bLastTurn` for span orientation.
- **`diff::event_turn`** — shared turn extraction (events without a turn —
  `session.open`, `page.declare`, pin/unpin — are None); exported for reuse.

### `diff` CLI (`rust/crates/ctxvm-conformance/src/bin/diff.rs`)

```
diff <a.jsonl> <b.jsonl> [--output FILE]     # full TraceDiff JSON
diff --help                                  # exits 0
```

- **Exit contract:** 0 = shared region matches (identical or extension) ·
  1 = divergent inside the shared length · 2 = usage/IO/parse. This is the
  cross-check gate the memo's §4 verifies-by (`ctxvm diff session-a.jsonl
  trace-142.jsonl` → page-level divergence is only the suffix; shared prefix
  matches ⇒ exit 0).
- Composition note (same as T18): diff ≠ replay's fact gate — replay proves ONE
  trace's facts-vs-decisions; diff proves a RELATION between TWO traces. A
  replay-divergent trace can still be diff-clean against its own copy.

## 3. Honest deviations / limitations

- **Prefix-relative only.** The comparison is positional from event 0. Two same
  sessions recorded with an interleaved mismatch will read as early divergence —
  a session-id-aware alignment could relax that but would weaken the handoff
  gate this card promises; documented as a conscious non-feature.
- **Tallies at common facts compare END schedules** (replay's static-analysis
  semantics, not point-in-time replay). A prefix-safe window can be added if a
  forensic pass needs per-region tallies.
- **No byte-level mode.** Field order in files is not identity (decoded structs
  compare); a raw-bytes mode is intentionally left to consumers with different
  anchors (checksums sidebars per corpus drop already cover byte identity).
- T17 (`packages/hermes/`, Hermes workstream) was already in flight in this
  clone; this card touches the rust workspace only — no overlap.
