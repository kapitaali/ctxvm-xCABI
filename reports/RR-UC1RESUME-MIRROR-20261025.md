## Disclosed deltas & findings

1. **Reference scope vs design §3:** the hermes `resume()` implements the replay
   counterproof + checksums digest — NOT the manifest/checksums `-c` validation, the
   shared-prefix `diff`, or the projection surface. Mirror follows the reference (parity
   wins over design text); the witness chain test proves (3)/(4) as TEST-level evidence,
   in-module implementation stays v-next.
2. **Sidecar shape vs design §3:** the reference stores the whole evidence dict
   (`{snapshot, snapshotDigest, snapTurn, turn, artifacts}`), not the designed slim trio.
   Mirrored; contract §3 updated to the landed shape.
3. **zstd-missing latent crash:** hermes `resume()` calls `subprocess.run(["zstd", …])`
   without catching `FileNotFoundError` — a missing zstd CLI would crash
   `register()`/the boot check. The mirror keeps the never-block law (loud unverified
   failure instead). zstd is present on dev and CI hosts; disclosed as a latent hermes
   fix candidate, NOT patched in their file (their lane owns it).
4. **Glob nuance mirrored:** the reference `glob("trace-*.jsonl.zst")` does not filter
   directories — mirrored (no isFile filter on the zst listing).
5. **Pause-time dead code (pre-existing, unpatched):** `pause()`'s replay counterproof
   aims at a literal `trace-N.jsonl.zst` path that is never created by pause (the export
   artifact name carries the turn) — `verified: True` on pause is therefore unproven;
   surfaced 2026-10-25 in recon; remains their lane's to own (not touched by this card).
