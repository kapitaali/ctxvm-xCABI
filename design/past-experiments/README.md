# Past experiments

Owner-cleared archive 2026-11-26. This subdirectory holds closed or historical experiment designs,
preregistrations, runbooks, prompts, task fixtures, and closure notes moved out of the root of
`design/` so the root remains focused on product-design documents.

## Archived prefixes

Files keep their original basenames. Old references use this mapping:

- `design/W8*` → `design/past-experiments/W8*`
- `design/w8*` → `design/past-experiments/w8*`
- `design/TB-*` → `design/past-experiments/TB-*`
- `design/G4-LANE-DEVELOPER-PROMPT.md` → `design/past-experiments/G4-LANE-DEVELOPER-PROMPT.md`
- `design/H16-H18-LANE-DEVELOPER-PROMPT.md` → `design/past-experiments/H16-H18-LANE-DEVELOPER-PROMPT.md`
- `design/EXP-SURFACE-PROMPT.md` → `design/past-experiments/EXP-SURFACE-PROMPT.md`
- `design/exp-surface.md` → `design/past-experiments/exp-surface.md`

Active documentation, prompts, code comments, tools, and paper references were updated. Closed
`reports/LOG.md`, append-only spend ledgers, frozen `benchmarks/w8/**`, and another lane's dirty
`handoff/PROJECT-STATE.md` were not rewritten; use the mapping above when reading those historical
locators.

Future authorized run plans belong in `../experiment-runs/`. Product designs remain at the root of
`design/`.
