# W8 task freeze — four templates, their checkers, and the five amendments

Plan of record: `design/w8-run-plan.md`. This directory is the freeze: task texts, fixtures,
expected vectors, checkers and page profiles, all committed before any paid call.

`profile.json` in each template is generated by `../profile.py` from the fixture bytes — the
number is reproducible, not a model claim. The bound is `ceil(chars/4)`, the repo's own
`apx4-char` counting law (`rust/crates/ctxvm-tokenizer/src/lib.rs:51`).

T2's 67 pages sit seven above the plan's 40–60 band. The overrun is the shape of the
fixture, not padding: 54 small files cannot pack into fewer than 54 parts, and the band's
purpose (many small pages, no single huge read) is met. Recorded, not hidden.

## The five amendments of 2026-11-07, and how each is met

1. **Pressure.** Every template carries a fixture-derived bound (§ above); all four clear
   45,000 tokens, so none is a floor control and none needs reclassification. The earlier
   measurements (~7k for T1's six files, ~19.4k for eight drop summaries, ~4.5k for twelve
   LOG rows) are gone: T1 now spans 20 files (six binaries, conformance library, core and
   codec public surface, tokenizer), T2 digests every trace in the corpus, T4 audits all 162
   rows instead of quoting twelve.
2. **Non-empty violator sets.** T3's five behaviours are implications over file text, and
   `build_expected.py` refuses to emit an empty list (raises) while `checker.py` exits 2 on a
   frozen fixture with an empty list and fails any answer whose lists are all empty. Measured
   counts: B1 8, B2 1, B3 5, B4 1, B5 5.
3. **Explicit paths, never globs.** `fixture.json` in every template is a literal path list
   (T1 20, T2 54, T3 20 — the strict `packages/*/src` set, T4 1).
4. **`sessions` is not derivable from rows.** T2 records `null` where a drop has no sidecar
   and names the files it checked; where sidecars exist it counts distinct `sessionID` values
   and names the sidecars. m1 is the `null` case; m8 is the trap where two traces carry one
   session.
5. **DQ trap.** Expected artefacts carry ids, dates, tracks, counts and relative paths only.
   `dq-expected.sh` scans every expected artefact to zero matches before the first paid call.
   The scanner is extension-gated (`*.jsonl`, `*.meta.json`, `*.provenance`), so each artefact
   is copied byte-for-byte under a `.meta.json` name for the scan; the verdict is about
   content, and the re-extension is stated here rather than hidden.

## Invocation contract (measured, not assumed)

On Hermes v0.23.0 a `-z` run does not load plugins in its own process:
`hermes_cli/cli_single_query.py:486` says the turn's plugins run in the gateway (PLG-7), and
one gateway multiplexes every profile (`hermes gateway status`: "default-profile
multiplexer"). Therefore a run's `CTXVM_TRACE_DIR`/`CTXVM_TRACE_NAME` come from the gateway's
environment, not the runner's. Owner ruling A′: the gateway carries one shared pool, and each
run's capture is located by the session id the run itself reports (`--usage-file`) and copied
into `<runs>/<task>/<arm>-r<round>/`. Per-task alternation is preserved; one gateway restart
applies the pool.

## What is not here

T5 (test triage) and T6 (invariant rename) are not built: the second repository's own suite is
green (`python -m pytest -q tests mcp_server_test.py` → 7 passed) and it has no spec-stated
rename spanning ~12 modules. Building either would mean seeding defects — a synthetic fixture,
which `design/w8-run-plan.md` §3 rejects. Recorded as a finding, not papered over.

The pilot (template 1, both arms, one round) has not run: it needs the gateway restart, which
restarts this CLI session too.
